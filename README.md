# Anchor Web Design Studios

Responsive static site for Anchor Web Design Studios. The project preserves the original horizontal storytelling, flip-card portfolio interactions, console-style headings, and black-and-gold executive pages while sharing accessibility and responsive refinements.

## Local workflow

1. `npm install`
2. `npm run dev`
3. `npm run audit`
4. `npm run test:ten`

The AI concierge and owner project dashboard currently use browser storage as a transparent prototype data layer. Production authentication, server-side storage, and email delivery should be connected before using the dashboard for sensitive client data.
